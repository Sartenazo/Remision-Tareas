# Remisión de Tareas

Aplicación del móvil para apuntar partes de trabajo en el campo (Máquina, Vendimiadora,
Cosechadora, Tratamientos, Trabajos a terceros, Mis horas y Reparaciones), con o sin cobertura.

Funciona **sin nube**:

- La oficina manda un **archivo de listas** (empresas, parcelas, máquinas, productos, trabajadores…)
  desde Access → botón «Enviar listas al móvil (archivo)». El trabajador lo abre en la app.
- Los partes se mandan a la oficina en un **archivo** que se comparte por WhatsApp, correo, Bluetooth…
  En Access → botón «Importar partes desde archivo».

Dirección: https://sartenazo.github.io/Remision-Tareas/
